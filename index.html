Instalare în trei pași

01

Instalează Ollama

Descarcă Ollama de pe site-ul oficial. Zen Local îl va porni automat.

02

Descarcă și extrage ZIP-ul

Folosește „Extract all”, apoi deschide folderul extras.

03

Instalează Zen Local

Dă dublu clic pe Instaleaza_Zen_Local.vbs. Aplicația creează pictograme pe desktop și în Start.

Prima pornire: dacă nu ai un model instalat, apasă în aplicație „Descarcă modelul recomandat”. Descărcarea modelului cere internet și spațiu liber; după aceea, generarea codului se face local.
Confidențialitate: textul cererii este trimis către Ollama local. Dictarea vocală este o funcție separată și poate trimite audio către serviciul de recunoaștere al browserului.

Întrebări frecvente

Pot folosi site-ul ca să generez cod direct aici?

Site-ul public distribuie aplicația. Generarea se face în aplicația Zen Local, folosind Ollama instalat pe calculatorul utilizatorului.

De ce cere Ollama?

Ollama rulează modelul AI local. Zen Local îl pornește automat, dar instalarea Ollama este separată.

De ce afișează Windows un avertisment?

Pachetul nu este semnat digital. Windows poate afișa „Editor necunoscut” la prima pornire.

Funcționează pe macOS sau Linux?

Acest pachet este construit pentru Windows 64-bit.
